# Bigtop Player 0.2.0

This release is about running a real show without surprises.
Problems show up before you reach them, the system stays awake, and Bigtop can start cues in Ontime.

## Highlights

- **No surprise mid-show.** Every 10 s the app checks that the show's audio files are still there and unchanged. A missing one turns its row red and shows a banner over the list at once. GO on a step whose file cannot play moves NEXT on to the next playable step and says why.
- **Show check** (in Show settings, and from the banner) lists every problem in one place: missing or changed files, failed or unfinished imports, the audio device, Art-Net and Ontime. Or it says All clear.
- **Ontime.** GO can start an Ontime cue (Bigtop tells Ontime, over Ontime's HTTP API). Pause, Resume and Esc can follow too. A status light shows whether Ontime answers; shows that do not use Ontime show no light.
- **Safer during a show.** The system does not sleep in Rehearsal and Show mode. Closing the app in Show mode asks first. Deleting a step that is playing asks first, and its sound plays on.
- **Imports.** AIFF and Ogg Vorbis files can be dropped too. A progress bar on each importing row and "Importing 3 of 10" in the status bar. A failed import has a Retry button. New steps start at -6 dB (a show setting), so there is headroom to push them louder.
- **About** in Settings names the version, the licence and the project page.

## Upgrading

Shows from 0.1.0 open as they are.
Ontime stays off unless the show already named an Ontime host.
Steps you already have keep their levels; only newly dropped files start at the show's level for new steps.

## Known limits

- Ontime works in one direction only (Bigtop to Ontime); Ontime cannot trigger Bigtop yet.
- m4a/AAC files cannot be imported yet; convert them to WAV or FLAC first.
- A file that was missing when the show opened turns normal only after a restart once it is back.
